# L'Étoile Bistro - Modern Fine Dining & Gastronomy Website

An artisanal, Michelin-inspired French restaurant web application featuring dynamic real-time hours, interactive tasting wishlist, dish provenance explorer, and a full table reservation booking engine.

## 🌟 Highlights & Features
- **Editorial Luxury Design System**: Warm tactile depth with Playfair Display and Plus Jakarta Sans.
- **Dynamic Live Hours**: Real-time status indicator (Dinner 17:30–23:00, Weekend Brunch 10:30–14:30, Monday Mise en place).
- **Interactive Specialties Menu**: Course filtering (Starters, Mains, Desserts, Cocktails), dietary tags, and instant search.
- **Tasting Wishlist Drawer**: Diners can curate their personalized dinner courses and attach them directly to reservation notes.
- **Table Reservation System**: Real-time validation, seating ambience options, evening prime slot picker, and confirmation receipt with **Add to Calendar (.ics)** generation.
- **Sommelier Grand Cellar**: Interactive wine & flavor profile matching.
- **Guest Impressions & Reviews**: Verified critic reviews + interactive guest review submission with local persistence.
- **Printable Michelin Menu**: Optimized print stylesheet for seasonal tasting menu and receipts.
- **Fully Responsive**: Mobile navigation drawer and high-resolution local photography.

## 🚀 Deployment on Vercel
This is a standard static web application. Deploying to [Vercel](https://vercel.com) requires zero configuration:
1. Connect your GitHub repository to Vercel.
2. Select the repository `Morden-restourant-website`.
3. Leave Build Command and Output Directory as default (static root).
4. Click **Deploy**.

## 💻 Local Development
To serve locally on Windows:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
```
Then visit `http://localhost:8080`.
